## Elliott Wave Theory Basics

### The 5-3 Wave Pattern

**Impulse Waves (5 waves):**
```
Bullish Impulse:        Bearish Impulse:

    5 •                     • 1
   /                         \
  /  • 3                      • 3
 / /                             \
• 2                               • 5
  • 1                      • 2
                           \  /
                            • 4
```

**Waves 1, 3, 5:** Motive waves (move with the trend)
**Waves 2, 4:** Corrective waves (pullbacks)

**Corrective Waves (3 waves):**
```
A-B-C correction after 5-wave impulse
```

### Elliott Wave Rules (Sacred!)

1. **Wave 2 never retraces more than 100% of Wave 1**
   - If it does, it's not Wave 2

2. **Wave 3 is never the shortest**
   - Wave 3 is usually the longest and strongest

3. **Wave 4 never overlaps Wave 1 price territory**
   - This maintains the impulse structure

### Guidelines (Flexible)

- Wave 2 typically retraces 38.2%-61.8% (Fibonacci)
- Wave 4 typically retraces 23.6%-38.2%
- Wave 3 often extends 161.8% of Wave 1
- Wave 5 often equals Wave 1 in length

## Why The Strategy Failed

### 1. **Fighting the Dominant Trend**

- Elliott Wave correctly identified a **bearish 5-wave pattern** on 15-min bars
- BUT SPY has a **long-term upward bias** (index appreciation)
- **Shorting a bull market = low win rate**

### 2. **Short-Term Wave vs Long-Term Trend Conflict**

```
15-minute timeframe:    Bearish wave structure ↓
Daily/Weekly trend:     Bullish uptrend ↑
Result:                 Conflict → shorts get stopped out
```

**Lesson:** Always trade WITH the higher timeframe trend, not against it.

### 3. **Timing vs Direction**

Elliott Wave told us **WHEN** to enter (after wave 5), but we chose the **WRONG DIRECTION** (short instead of long for the correction).

**Better approach:**
- Wave 5 completes → expect correction
- In a bull market, "corrections" are **buying opportunities**
- Should have taken **longs** on dips, not shorts on rallies

### 4. **85% Trend Break Exits**

- Most positions were stopped by upward momentum
- This is the market telling us: "You're on the wrong side"
- High percentage of one exit type = systematic bias error

## Correct Use of Elliott Wave

### ✅ What Elliott Wave IS Good For:

**1. Identifying Wave Position Within a Trend**
```
Example (Bullish):
- Wave 3 starting → Aggressive longs (strongest wave)
- Wave 4 pullback → Buy the dip
- Wave 5 → Reduce size, prepare for reversal
- Post Wave 5 → Trade the A-B-C correction
```

**2. Timing Entries in the Direction of Higher TF Trend**
```
Daily: Uptrend
15-min: Wave 4 pullback detected
Action: Enter long at Wave 4 low (buying the dip)
```

**3. Setting Price Targets**
```
Wave 3 target: 161.8% extension of Wave 1
Wave 5 target: Equal to Wave 1 length
Use these for take-profit levels
```

**4. Risk Management**
```
Stop below Wave 1 for Wave 3 trades
Stop below Wave 3 for Wave 5 trades
Clear, structure-based stops
```

**5. Multi-Timeframe Confluence**
```
Weekly: Bullish impulse (Wave 3)
Daily: Pullback (Wave 4)
15-min: Bullish impulse starting
Action: Strong long setup (aligned waves)
```

### ❌ What Elliott Wave Is NOT Good For:

**1. Trading Against Higher Timeframe Trend**
- What we did: Shorted because 15-min showed bearish waves
- What we should have done: Waited for bullish waves to align with daily uptrend

**2. Standalone Trading System**
- Elliott Wave alone doesn't account for:
  - Market regime (trending vs ranging)
  - Volume dynamics
  - News/catalysts
  - Overall market conditions

**3. Exact Price Prediction**
- Waves give probability ranges, not certainties
- Multiple wave counts are often valid
- Requires subjective interpretation

**4. High-Frequency Trading**
- Wave patterns need time to develop
- Best for swing trading (days to weeks)
- Less effective for scalping (minutes)

## Proper Elliott Wave Trading Rules

### Rule 1: **Align with Higher Timeframe**
```
Weekly/Daily trend → Trading bias
15-min waves → Entry timing
1-min price action → Execution
```

### Rule 2: **Trade Corrections, Not Reversals**
```
In uptrend:
- Bearish wave 5 ends → Buy the correction (A-B-C)
- Bullish wave 4 ends → Buy the Wave 5 impulse

In downtrend:
- Bullish wave 5 ends → Short the correction
- Bearish wave 4 ends → Short the Wave 5 impulse
```

### Rule 3: **Wait for Confirmation**
```
Don't predict waves → Confirm them
- Wait for Wave 3 to confirm impulse
- Wait for Wave 5 completion before trading correction
- Use other indicators (RSI, volume) for confirmation
```

### Rule 4: **Use Wave Ratios for Targets**
```
Fibonacci extensions:
- Wave 3 = 161.8% of Wave 1
- Wave 5 = 100% of Wave 1
- Wave C = 100% of Wave A

Use these for profit targets, not guesses
```

### Rule 5: **Structure-Based Stops**
```
Long in Wave 3: Stop below Wave 2
Long in Wave 5: Stop below Wave 4
Long in Wave C: Stop below Wave A

Clear, objective stop levels
```

- Use waves for targets (Fibonacci extensions)
- **Don't use waves to fight the primary trend**

### Bottom Line:

Elliott Wave is a **powerful tool when used correctly**:
- ✅ Timing tool within established trends
- ✅ Target-setting framework
- ✅ Risk management guide

But becomes **a losing strategy when misapplied**:
- ❌ Trading against higher timeframe trend
- ❌ Treating wave patterns as reversal signals
- ❌ Using on too-short timeframes

**For SPY: Always respect the upward bias. Use Elliott Wave to time LONG entries, not justify SHORT positions.**
